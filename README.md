## 🌟 Funcionalidades Principais

### 1. 📥 Download de Jogos (Ecossistema Hydra)
- **7 Fontes Oficiais Integradas**:
  - `https://hydralinks.cloud/sources/fitgirl.json` (**FitGirl Repacks**)
  - `https://hydralinks.cloud/sources/steamrip.json` (**SteamRIP**)
  - `https://hydralinks.cloud/sources/dodi.json` (**DODI Repacks**)
  - `https://hydralinks.cloud/sources/gog.json` (**Free GOG Games**)
  - `https://hydralinks.cloud/sources/xatab.json` (**Xatab Repacks**)
  - `https://hydralinks.cloud/sources/atop-games.json` (**Atop-Games**)
  - `https://hydralinks.cloud/sources/empress.json` (**Empress Releases**)
- **Filtros e Recursos**:
  - Busca instantânea por título, categoria e fonte.
  - Botão de **1-Click Magnet** para abrir direto no torrent.
  - Links de download direto (**Direct Play / DDL**).
  - Modal com requisitos de sistema (CPU, GPU, RAM, Armazenamento).
  - Gerenciador de Fontes Hydra com importador de JSON local/remoto e botão para copiar links para o **Hydra Launcher**.

### 5. 🛠️ Apps para PC (Ferramentas & Runtimes)
- **⚡ Desempenho & FPS**: Lossless Scaling (Frame Gen LSFG), MSI Afterburner + RivaTuner, Mem Reduct (Limpador de RAM), Display Driver Uninstaller (DDU), ReShade.

- **🕹️ Controles**: DS4Windows (DualShock 4 / DualSense no PC).

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) (v18+)
- [npm](https://www.npmjs.com/)

### Instalação

```bash
# Clone o repositório
git clone https://github.com/jpjohngithub/johnplay.git

# Acesse a pasta do projeto
cd johnplay

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Abra no navegador em **http://localhost:5173/**.

### Build de Produção

```bash
npm run build
```
